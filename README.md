### Project Plan

Sprint 0 - Infrastructure Foundation
Rail
Develop a proof-of-concept rail mounting system that establishes the foundation for the RodDock platform.
Establish the rail geometry and validate that the concept works.

Sprint 1 - Platform Foundation
Adapter
Design and build a universal adapter that connects the RodDock rail to standardized accessories.
Create the universal bridge between the rail and future accessories.
This defines the RodDock interface contract.

Sprint 2 - Reference Product
Fishing Rod Holder
This is the first product built on the platform.
Its job is not only to hold a fishing rod, but also to validate that the architecture (Rail ? Adapter ? Accessory Interface ? Accessory) works as intended.

Design and build the first RodDock accessory—a fishing rod holder—that integrates seamlessly with the universal adapter and securely supports a fishing rod.

Sprint 3 - Infrastructure Completion
Rail accessories
Extend the rail system so rail sections and end caps interlock using the same standardized interface.
Complete the rail itself by designing:

Interlocking rail joints
End caps
Any remaining "infrastructure" pieces

After Sprint 3, the entire RodDock ecosystem exists:

Rail
Adapter
Accessory
Rail accessories
